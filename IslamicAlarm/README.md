# Islamic Alarm

কাস্টম টাইম-বেজড এলার্ম অ্যাপ (Android)। এলার্ম বাজলে সাউন্ড না বাজিয়ে ফুলস্ক্রিন
ইসলামিক ব্যাকগ্রাউন্ড + আয়াত + কাউন্টডাউন দেখায়, এবং নির্ধারিত সময় শেষ না হওয়া
পর্যন্ত ব্যাক/হোম বাটন কাজ করে না (ইনকামিং কল ছাড়া)।

## GitHub থেকে APK বানানো

1. এই পুরো ফোল্ডার একটা নতুন GitHub রিপোজিটরিতে পুশ করো:
   ```
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <তোমার-রিপো-URL>
   git push -u origin main
   ```
2. GitHub রিপোর **Actions** ট্যাবে যাও — পুশ করার সাথে সাথে "Build APK" workflow অটো রান হবে।
3. Workflow শেষ হলে সেখানে **Artifacts** সেকশনে `islamic-alarm-debug-apk` নামে zip
   পাবে — ডাউনলোড করে ফোনে APK ইনস্টল করো (Unknown apps থেকে ইনস্টলের অনুমতি লাগবে)।

## ফোনে প্রথমবার সেটআপ (জরুরি)

অ্যাপ ইনস্টলের পর দুইটা পারমিশন/সেটিং ম্যানুয়ালি অন করতে হবে, নাহলে ফিচার ঠিকমতো কাজ করবে না:

1. **Exact Alarm পারমিশন** — অ্যাপ ওপেন করলেই এটা চাইবে, অনুমতি দাও (Android 12+)।
2. **Screen Pinning (App Pinning)** — Settings → Security (বা Apps) → Advanced →
   App pinning → চালু করো। এলার্ম প্রথমবার বাজলে সিস্টেম একটা "Pin this app?"
   কনফার্মেশন দেখাতে পারে — Accept করলে পরের বার থেকে স্বয়ংক্রিয়ভাবে পিন হবে।

## সততার সাথে যা জানা দরকার (Limitations)

- **সম্পূর্ণ আনব্লক-প্রুফ না** — Android-এর সাধারণ Screen Pinning ব্যবহারকারীকে
  Back + Recents বাটন একসাথে চেপে ধরে (বা নিচ থেকে সোয়াইপ করে ধরে রেখে) নিজেই
  আনপিন করার সুযোগ দেয়। এটা Android-এর সিস্টেম-লেভেল ডিজাইন, অ্যাপ থেকে সম্পূর্ণ
  বন্ধ করা যায় না — যদি একদম আনপিন-প্রুফ চাও, তাহলে অ্যাপকে **Device Owner** বানাতে
  হবে (factory-reset ফোনে QR/ADB দিয়ে provision করতে হয়) — এটা অনেক বেশি জটিল,
  চাইলে পরে যোগ করে দিতে পারি।
- **iOS-এ এই ফিচার সম্ভব না** — Apple থার্ড-পার্টি অ্যাপকে হোম বাটন/সোয়াইপ ব্লক করার
  অনুমতি দেয় না।
- কল হ্যান্ডলিং টেলিফোনি ব্রডকাস্টের ওপর নির্ভরশীল — কিছু কাস্টম Android স্কিনে
  (MIUI, ColorOS ইত্যাদি) ব্যাটারি-অপ্টিমাইজেশন অ্যাপকে ব্যাকগ্রাউন্ডে বন্ধ করে
  দিতে পারে; অ্যাপকে "No battery restriction" দিয়ে রাখা ভালো।
- ব্যাকগ্রাউন্ড ছবি এখন একটা সাধারণ ভেক্টর (মসজিদ সিলুয়েট + গ্রেডিয়েন্ট) —
  `app/src/main/res/drawable/lock_background.xml`-এ নিজের পছন্দের ছবি বসাতে
  পারবে (drawable এ PNG/JPG রেখে ImageView-এর src পরিবর্তন করে)।

## প্রজেক্ট স্ট্রাকচার (সংক্ষেপে)

- `MainActivity.kt` — এলার্ম লিস্ট, অ্যাড/এডিট/ডিলিট
- `AlarmScheduler.kt` — AlarmManager দিয়ে শিডিউল করা
- `AlarmReceiver.kt` — এলার্ম ট্রিগার হলে LockScreenActivity চালু করে
- `LockScreenActivity.kt` — ফুলস্ক্রিন লক, কাউন্টডাউন, স্ক্রিন পিনিং, কল হ্যান্ডলিং
- `BootReceiver.kt` — রিবুটের পর এলার্ম রি-শিডিউল
- `.github/workflows/build-apk.yml` — অটো APK বিল্ড
